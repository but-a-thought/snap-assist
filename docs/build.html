Signed arm64 builds

This branch provides Developer ID signing, verified packaging, and a fixed installation location. Both Debug and Release target Apple silicon only. The original MIT license and attribution remain in the app.

The upstream self-signed setup helper is retired. Do not follow the original README’s local-key setup instructions for this branch. Use an existing Developer ID Application identity in your login keychain. No private-key export is required.

1. Choose an installed signing identity

Use a Mac with Xcode installed and a Developer ID Application certificate with its private key available in your login keychain. View the available identities:

security find-identity -v -p codesigning

In Terminal, change to this repository’s folder. Set these two inputs, replacing the placeholders with your identity fingerprint and Team ID. Apple Development and ad-hoc identities will not pass the installer’s Developer ID checks.

export SIGN_IDENTITY='YOUR_DEVELOPER_ID_APPLICATION_FINGERPRINT'
export EXPECTED_TEAM_ID='YOUR_TEAM_ID'

Personal wrappers may be stored in the ignored local directory below. Keep private keys in your keychain; use 1Password for any separately needed secrets.

.local/

2. Build and verify

The builder selects Xcode through a scoped developer directory, builds arm64, packages resources, signs with hardened runtime and a secure timestamp, and verifies the result before replacing a previous build. A missing identity, failed signature, wrong Team ID, or unexpected architecture stops the workflow.

bash scripts/build-app.sh release
bash scripts/build-app.sh debug

Outputs:

dist/release/SnapAssist.app
dist/debug/SnapAssist.app

3. Install and open Release

This command builds, verifies, and installs Release. Installation gracefully quits the installed instance, verifies a temporary copy, and retains any previous app at the backup location printed by the installer. Replacement failures attempt to restore that backup.

bash scripts/build-app.sh release install
open /Applications/SnapAssist.app

The stable installation location and bundle identifier are:

/Applications/SnapAssist.app
com.frank.snapassist

4. Grant permissions once

In System Settings → Privacy & Security → Accessibility, enable Snap Assist. Screen Recording is optional: it enables window thumbnails; without it the picker shows icons. Restart the app using its menu if macOS requests it after a permission change.

Future builds should use the same bundle ID and Developer ID signing requirement. Validate permission persistence on your Mac; do not reset privacy permissions as part of rebuilding. This personal workflow does not notarize the app or create a distribution package.

To show suggestions, newly snap a window to a left or right half, for example with Window → Move & Resize → Left. Clicking an already tiled window does not reopen the picker. Detection polls every 120 milliseconds and waits for two matching readings; animation and thumbnail loading can add latency.

Security changes

  • Persistent Shift-drag logging removed; existing log files are left untouched.
  • Centering installs its global event monitor only while enabled, and clears gesture state when disabled.
  • Both restart actions use the same shell-free helper mode, waiting up to ten seconds for the old process to exit. A timeout does not launch another instance.
  • Signing failure cannot install or replace a previous verified build. No key-generating helper remains active.
  • The ordinary full-screen Dock canvas no longer suppresses the picker or all resize dividers. Mission Control suppression distinguishes legacy Dock layer 18 from macOS 27 WindowManager layer 19. These system compositor details remain heuristics and may change in future macOS versions.

Regression checks

The workflow tests use mocked compiler/signing boundaries and do not use your signing key. Swift tests exercise the monitor lifecycle and restart behavior.

python3 Tests/build-workflow-tests.py
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test --arch arm64

The executable’s existing self-check can print personal window titles. Inspect its output before sharing. Full functional tests may move a foreground window; use disposable test windows.

/Applications/SnapAssist.app/Contents/MacOS/SnapAssist --check

Developer ID signing establishes identity and integrity. It does not guarantee safety or replace review of future source changes.
